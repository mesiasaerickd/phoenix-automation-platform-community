# PAP — Frequently asked questions / Preguntas frecuentes

**Are the images public? / ¿Son públicas las imágenes?** Yes / Sí. Six RC1 images are published in GHCR; no personal access token is required for standard installations.

**Which branch? / ¿Qué rama?** Use `prd` for installation, `dev` for development, and `contrib` for community documentation.

**Do I need Kubernetes? / ¿Necesito Kubernetes?** Yes, Kubernetes or K3s must already be prepared.

**Where can I ask questions? / ¿Dónde preguntar?** Use GitHub Discussions for general questions, and Issues for reproducible defects. Do not post credentials or private infrastructure details.

**Is there guaranteed support? / ¿Hay soporte garantizado?** No. The project is community maintained without SLA.
